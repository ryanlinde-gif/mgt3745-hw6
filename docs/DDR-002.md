# DDR-002: Google AI Studio Build

## Task

The same feature, **F3, Share of Top Skills Held**, and the same three EARS
rows. The same file, [prompts/PROMPT.md](../prompts/PROMPT.md), pasted once,
unchanged, with nothing added or removed between the two builders. No follow-up
prompt was sent.

## Tool and Model

Google AI Studio, 2026-10-20, Gemini as served in the Build interface.

## Economic Rationale

| | Hours |
|---|---|
| Build F3 by hand, at my HW4/HW5 pace | 2.0 |
| The delegation itself | 0.2 |
| Evaluating the output and extracting the arithmetic | 0.6 |
| **Net** | **+1.2** |

Was it worth it? **Yes, and unlike DDR-001 the output is usable.** It arrived
as one file of plain HTML, CSS and JavaScript with no dependencies, which is
the stack ADR-001 already chose, so the 0.6 hours of review is the whole cost
rather than the beginning of a rewrite. The twelve-skill defect found by
`npm test` is a two-line fix.

The honest caveat: 2.0 hours is my estimate of my own pace on three rows of
arithmetic, and I may be flattering the delegation. Of the 1.2 saved, the part
I would defend is the CSS and the layout, not the logic.

## Trust Boundary

## Retries and Changes

**Retries: none.** One prompt, one build.

**Changes: one, and it is structural rather than logical.** AI Studio returned
a single `.html` file rather than a project archive. The assignment asks for
`builds/aistudio.zip`, so I placed the file unchanged at
`builds/aistudio-src/index.html` and zipped that one file. Not a byte of it was
edited.

I also extracted its arithmetic from `updateDisplay()` into
`evals/impl/aistudio.js` so the shared test could call it, removing only the
DOM writes. The logic, including the missing cap at ten, is copied as written.
**Fixing that bug during extraction would have hidden the most useful thing
this comparison found**, so it is preserved and the test fails against it on
purpose.

## Verification Performed

The same two checks bolt faced, so the comparison is fair.

Row by row against F3-1, F3-2 and F3-3 in [COMPARISON.md](../COMPARISON.md),
each cell citing a file and line. **F3-2 and F3-3 Pass. F3-1 Partial.**

Then the four code-eval checks in `evals/shared.test.js`. **AI Studio passed 3
of 4.**

**The failure, stated plainly.** `updateDisplay()` computes
`totalRanked = role.skills.length` and never caps it at ten. F3-1 says the
count is against "the 10 top-ranked skills." Every role AI Studio invented for
itself has ten skills or fewer, so the defect is invisible in its own build, in
its own screenshots, and to any reviewer reading its output instead of its
logic. It surfaces only when both builds are handed the same twelve-skill role
by a test neither of them wrote.

**What I could not verify.** Whether AI Studio would have capped at ten had its
own sample data forced the question. I did not ask it, because a follow-up
prompt would have broken the one-prompt rule that makes this comparison fair.
