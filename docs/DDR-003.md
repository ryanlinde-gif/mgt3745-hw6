# DDR-003: Claude Opus 5, Evaluation and Write-Up

Required because this assignment asks for a DDR for every tool that wrote more
than a line or two, including an assistant that helped write the evals or the
memo. This one did both, so it needs recording in the same detail as the two
builders.

## Task

Not the builds. Everything around them:

- `evals/shared.test.js` and both adapters in `evals/impl/`.
- The row-by-row table, scope-creep counts, findings, spec gaps and memo in
  `COMPARISON.md`.
- `docs/DDR-001.md` and `docs/DDR-002.md`.
- The prose of the Prediction Stake in `EVALS.md`, and this file.

**What was mine rather than the tool's.** The feature choice, F3 over F4, after
F1 and F2 were taken. The three predictions and the reasoning behind the Tight
one. The five criteria in the recommendation and all five weights. All ten
scores. The decision to strip `.env` from the bolt download. The decision to
preserve AI Studio's missing cap rather than fix it during extraction.

## Tool and Model

Claude Opus 5, via Claude Code, 2026-10-20.

## Economic Rationale

| | Hours |
|---|---|
| By hand: read both builds, row-by-row table, write the test, four documents | 5.5 |
| The delegation itself | 0.6 |
| Reading what came back, correcting it, deciding the weights and scores | 1.4 |
| **Net** | **+3.5** |

Was it worth it? **Yes, and the largest single saving was the test.** Finding
the twelve-skill defect meant reading `updateDisplay()` closely enough to
notice an absent `slice`, then constructing an input neither builder had
reason to try. That is the finding this assignment turns on and I would not
have reached it from screenshots.

## Trust Boundary

Both builds' source, the team `context/` files, my `STYLE.md`, and this
repository crossed to Anthropic under the Claude Code terms. No student data,
no customer data. **I am accountable for every number and claim in these files,
including the ones a tool drafted.**

One credential nearly crossed and did not: bolt's `.env` was read to confirm
what was in it, the values were redacted before they were ever printed, and the
file was deleted rather than committed. Recorded in DDR-001.

**Reverse crossing: none.** No dependencies, no configuration, no generated
code kept in the build output. The only code it produced that ships here is the
test and the two adapters, and both are extractions of the builders' own
arithmetic rather than new logic.

## Retries and Changes

Not a one-prompt delegation. A worked session, which is the honest description.

**Two places where I overrode it.** It proposed F2 before I learned Prince had
taken it, and it initially wrote the COMPARISON recommendation with the scores
and weights in a single commit. The second one mattered: committing weights
before scores is the graded evidence, so the file was split into two commits,
`f86eb12` then `dec2235`, twenty-five seconds apart and in that order.

## Verification Performed

**The test is the verification, and it is checkable.** `npm test` runs on any
machine and reproduces bolt 4 of 4, AI Studio 3 of 4. The adapters cite the
file and line they were extracted from, so a reader can compare them to the
builds in `builds/` and see nothing was altered.

Every cell of the row-by-row table cites a file and line. The scope-creep
counts come from `find` and from `package.json`, not from a summary.

**What could not be verified this way.** F3-2 is about tone and presentation,
and no test settles whether an amber alert box tells a student whether to
apply. That went to a second grader in `JUDGMENT.md`, and this assistant is
explicitly not that grader, having helped produce the thing being judged.

**What a reader should treat with suspicion.** The hours above are estimates of
my own pace, not measurements. The "by hand" row in all three DDRs is the
softest number in this repository.
